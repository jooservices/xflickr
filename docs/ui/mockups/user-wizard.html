Setup wizard

Static mockup for docs/ui/views/user-wizard.md. No script, no network. Each state is shown in light and dark, at 1440 px desktop and 390 px mobile. Required states: ready, loading, empty, error; the others are variants the spec defines.

Ready, step 1

Normal first visit: BYOK explainer, key and secret, Check key.

XFlickr

Step 1 of 3 · Your API key

Bring your own Flickr API key

XFlickr has no key of its own. Create one on Flickr, then paste the key and secret. They are stored encrypted and used only for your crawl. Create a key on Flickr

Why your own key?
Flickr gives every key 3,600 calls per hour. With your own key your crawl uses your own quota and never waits behind other people.
