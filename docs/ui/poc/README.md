# XFlickr UI proof of concept

`xflickr-poc.html` is the approved interactive proof of concept: one static page, no backend, all data generated in the page. Open it in a browser, switch between the User role (light gallery) and the Admin role (dark control room), and use the Preview control to see the loading, empty and error state of every screen.

It is the visual and behavioural baseline for the view specifications in `docs/ui/views/`. It is reference only: it is not part of the application build and must not be edited. Mock nodes in the proof show WireGuard addresses and foreign regions; the real design has no WireGuard.
